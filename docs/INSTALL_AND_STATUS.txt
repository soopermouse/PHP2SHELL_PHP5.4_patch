PHP 5.4.16-48.el7 security backport (RC1) — install notes
==========================================================

What's here
-----------
- patches/01..06-*.patch
    The six source changes, in the order the spec applies them.
- patches/php54-RHEL48-CVE-2026-109618-109619-COMBINED.patch
    The same six changes as a single diff, for an already Red Hat-patched
    5.4.16-48 tree. Do not apply this and the six split patches both.
- rpm/
    The -48 spec with the patches wired in (Patch200-205), the spec diff,
    and the build script.
- tests/release-gate/
    Build and Apache mod_php staging checks.

You supply the original php-5.4.16-48.el7.src.rpm yourself, from your RHEL
subscription. It is not included here.

Building
--------
On an isolated RHEL 7 build host, not production:

    cd php54-rhel7-security-backport
    sha256sum -c SHA256SUMS
    bash build-from-repo.sh /absolute/path/to/php-5.4.16-48.el7.src.rpm

build-rc.sh installs the source RPM into your rpmbuild tree and runs
rpmbuild -bp/-bs/-ba, so use a clean, dedicated build area.

Status
------
The six patches, the combined patch, the spec integration and the release-gate
scripts are all in place, and the source side has been tested on a local
CLI/CGI/FPM build: it compiles, passes the regression suite, and the targeted
OOM, multipart and request-state cases behave correctly.

Before this can go to production it still needs the binary RPMs built, testing
under Apache mod_php on staging, package signing, a rollback check, and an
independent security review. Until then it's a source candidate, not an
approved update.
